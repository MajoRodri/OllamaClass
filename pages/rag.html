RAG — Habla con tus Documentos

Las IAs tienen dos problemas clásicos: no conocen tus archivos privados (tus apuntes, tus PDFs de trabajo) y a veces inventan información cuando no saben algo —lo que se llama "alucinación".

RAG (Retrieval Augmented Generation) resuelve ambos problemas. En vez de que la IA intente recordar todo de memoria, le das tus documentos y le ordenas que solo responda basándose en ellos. Es como dejarle hacer el examen con el libro abierto.

🟢 Camino fácil — Sin código

Usa Open WebUI o AnythingLLM. Solo arrastras tu archivo PDF o Word al chat y el sistema activa el RAG automáticamente. Sin instalar nada extra, sin programar nada. Ideal para empezar.

⚡ Camino técnico — Python

Usa Python con LangChain y ChromaDB para tener control total sobre el sistema. Te permite personalizar cómo se busca, cómo se fragmenta el texto y cómo responde la IA. El código completo está abajo.

rag_stark.py — Código completo 
# ============================================================
# PROTOCOLO RAG — Habla con tus documentos privados
# Conecta Ollama (JARVIS local) con cualquier PDF tuyo
# ============================================================

# ── 1. IMPORTAR HERRAMIENTAS ──────────────────────────────
from langchain_community.document_loaders import PyPDFLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_community.vectorstores import Chroma
from langchain_community.embeddings import OllamaEmbeddings
from langchain_community.llms import Ollama
from langchain.chains import create_retrieval_chain
from langchain.chains.combine_documents import create_stuff_documents_chain
from langchain_core.prompts import ChatPromptTemplate

# ── 2. CARGAR EL PDF ──────────────────────────────────────
# PyPDFLoader lee el PDF y lo convierte en texto plano.
print("📄 Escaneando documento confidencial...")
loader = PyPDFLoader("manual_stark.pdf")
documentos = loader.load()

# ── 3. CORTAR EL TEXTO EN PEDAZOS (Chunking) ─────────────
# Los modelos de IA no pueden leer 500 páginas de golpe.
# chunk_size=1000: máximo 1000 caracteres por pedazo
# chunk_overlap=200: 200 caracteres se repiten entre pedazos
#   para no cortar ideas a la mitad.
print("✂️  Fragmentando el texto...")
cortador = RecursiveCharacterTextSplitter(
    chunk_size=1000,
    chunk_overlap=200
)
fragmentos = cortador.split_documents(documentos)

# ── 4. CONVERTIR TEXTO EN NÚMEROS (Embeddings) ────────────
# El modelo 'nomic-embed-text' convierte cada fragmento
# de texto en una lista de números (coordenadas matemáticas).
# Chroma guarda esos números en tu disco para buscar después.
print("🔢 Traduciendo texto a coordenadas matemáticas...")
boveda = Chroma.from_documents(
    documents=fragmentos,
    embedding=OllamaEmbeddings(model="nomic-embed-text")
)

# ── 5. CONFIGURAR EL BUSCADOR ─────────────────────────────
# Cuando llegue una pregunta, este buscador encontrará
# los 3 fragmentos de tu PDF más parecidos a esa pregunta.
buscador = boveda.as_retriever(search_kwargs={"k": 3})

# ── 6. CONECTAR CON OLLAMA ────────────────────────────────
llm = Ollama(model="llama3.2:3b")

# Instrucciones estrictas: SOLO responde con el texto encontrado.
# {context} es donde el sistema inyecta los 3 fragmentos del PDF.
prompt = ChatPromptTemplate.from_messages([
    ("system",
     "Eres JARVIS, el asistente de Tony Stark. "
     "Usa ÚNICAMENTE los fragmentos que se muestran abajo para responder. "
     "Si la respuesta no está ahí, di: 'Señor, no tengo esa información en los registros'. "
     "Sé directo y elegante. Máximo 3 oraciones.\n\n{context}"),
    ("human", "{input}"),
])

# ── 7. UNIR TODO EN UNA CADENA ────────────────────────────
cadena = create_stuff_documents_chain(llm, prompt)
sistema_rag = create_retrieval_chain(buscador, cadena)

# ── 8. HACER LA PREGUNTA ──────────────────────────────────
pregunta = "¿Cuáles son las especificaciones del reactor Arc?"
print(f"\n🤖 Preguntando a JARVIS: {pregunta}\n")

respuesta = sistema_rag.invoke({"input": pregunta})

print("=" * 52)
print(respuesta["answer"])
print("=" * 52)
